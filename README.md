# Помощник электрика

Бесплатное Android-приложение с открытым исходным кодом для электриков. Нет рекламы, регистрации, аналитики или скрытой отправки пользовательских проектов.

**Статус:** 0.5.0-alpha. Это не нормативно проверенная программа для проектирования безопасных электросетей.

**Технологии:** Kotlin, Jetpack Compose, Room/SQLite; Supabase только для публикации каталога.

## Что уже есть
- Объекты: создание, переименование, копирование, удаление; ручной экспорт/импорт резервных копий проектов в JSON.
- Электрощит: предварительный перечень аппаратов, поиск оборудования, смета с сохранением цен на момент добавления.
- Калькулятор тока, предварительный PDF сметы, светлая и тёмная темы.
- Встроенный офлайн-каталог и **кнопка «Обновить базу»**, которая сама скачивает опубликованный каталог по HTTPS с сервера.
- При ошибке сети или валидации локальная база остаётся доступна. Обновления каталога не переписывают старые сметы.

**Планировку помещений и прокладку кабельных трасс исключили из текущей дорожной карты по решению автора.** Кнопка «План» убрана. Старые данные помещений пока не удаляются из Room и резервных копий для совместимости — в новых версиях не редактируются.

## Каталог оборудования

Во вкладке «Ещё» показывается установленная версия. Кнопка **«Обновить базу»** проверяет сервер Supabase и при наличии новой версии загружает её. Пользователю **не нужно скачивать или выбирать файлы**. Каталог хранится на устройстве, а сам щит и смета работают офлайн.

Сервер: [как публикуются версии, права доступа и формат](docs/catalog/cloud-updates.md). Стартовая версия сервера — `2026.10.30.1` (32 условные позиции, цены ещё не заданы). Ручной импорт каталога через JSON удалён из интерфейса.

## Резервные копии проектов

В разделе «Объекты» доступны экспорт и восстановление **своих проектов** через системные диалоги Android. Для импорта создаётся новый объект, старый не заменяется. Подробности: [формат резервных копий](docs/project-backups.md).

## Сборка и тесты

JDK 17, Android SDK Platform 36, Gradle 8.13:

```bash
gradle :app:testDebugUnitTest :app:assembleDebug
```

GitHub Actions запускает unit-тесты, собирает debug APK и инструментальные тесты на Android-эмуляторе при pull request.

## Приватность и открытый исходный код

Для обновления базы требуется `INTERNET`: один запрос к публичному API Supabase **только после нажатия кнопки**. В запрос **не включаются** содержимое проекта, сметы, контакты или идентификатор пользователя. [Полная информация](PRIVACY.md).

Версия приложения (APK), push-уведомления, публичная страница донатов и Telegram-контакт будут добавлены позже.

## Важно

Подсчёт тока и приблизительная смета **не заменяют** подбор кабелей/защиты и проверку соответствия действующим нормам. До публичного релиза требуется полноценная инженерная проверка.
