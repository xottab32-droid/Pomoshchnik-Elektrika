# Помощник электрика

Бесплатное Android-приложение с открытым исходным кодом для электриков. Нет рекламы, регистрации, аналитики или скрытой отправки пользовательских проектов.

**Статус:** 0.7.0-alpha. Это не нормативно проверенная программа для проектирования безопасных электросетей.

**Технологии:** Kotlin, Jetpack Compose, Room/SQLite; Supabase только для публикации каталога.

## Что уже есть
- Объекты: создание, переименование, копирование, удаление; ручной экспорт/импорт резервных копий проектов в JSON.
- Электрощит: перечень аппаратов и **базовая графическая механическая компоновка DIN-реек** (6/12/18/24/36 модулей), выбор аппарата и установка на позицию или в первый свободный слот. Проверка вместимости и пересечений.
- Каталог: поиск, категории, цены из офлайн-базы. Неизвестные цены остаются неизвестными.
- Калькулятор тока, предварительный PDF сметы, светлая и тёмная темы.
- Встроенный офлайн-каталог и **кнопка «Обновить базу»**, которая сама скачивает опубликованный каталог по HTTPS с сервера.
- При ошибке сети или валидации локальная база остаётся доступна. Обновления каталога не переписывают старые сметы.

**Планировку помещений и прокладку кабельных трасс исключили из текущей дорожной карты по решению автора.** Кнопка «План» убрана. Старые данные помещений пока не удаляются из Room и резервных копий для совместимости — в новых версиях не редактируются.

## Каталог оборудования

Во вкладке «Ещё» показывается установленная версия. Кнопка **«Обновить базу»** проверяет сервер Supabase и при наличии новой версии загружает её. Пользователю **не нужно скачивать или выбирать файлы**. Каталог хранится на устройстве, а сам щит и смета работают офлайн.

Сервер: [как публикуются версии, права доступа и формат](docs/catalog/cloud-updates.md). Стартовая версия сервера — `2026.10.30.1` (32 условные позиции, цены ещё не заданы). Ручной импорт каталога через JSON удалён из интерфейса.

## Резервные копии проектов

В разделе «Объекты» доступны экспорт и восстановление **своих проектов** через системные диалоги Android. JSON v2 сохраняет DIN-рейки и расположение аппаратов, импорт старого JSON v1 работает. Для импорта создаётся новый объект, старый не заменяется. Подробности: [формат резервных копий](docs/project-backups.md).

## Сборка и тесты

JDK 17, Android SDK Platform 36, Gradle 8.13:

```bash
gradle :app:testDebugUnitTest :app:assembleDebug
```

GitHub Actions запускает unit-тесты, собирает временный debug APK **только для проверки** и выполняет инструментальные тесты на Android-эмуляторе. Debug APK с непостоянной подписью больше не публикуется как пользовательское обновление. В основной ветке выпускаются **постоянно подписанные release APK** с тем же сертификатом и возрастающим `versionCode`; это позволяет устанавливать обновления поверх приложения без удаления данных. [Настройка подписи и безопасный перенос со старых версий](docs/release-signing.md).

## Приватность и открытый исходный код

Для обновления базы требуется `INTERNET`: один запрос к публичному API Supabase **только после нажатия кнопки**. В запрос **не включаются** содержимое проекта, сметы, контакты или идентификатор пользователя. [Полная информация](PRIVACY.md).

В версии 0.5.1-alpha исправлено перекрытие системной строки состояния Android: верхняя панель учитывает `statusBarsPadding()`, а цвет значков согласуется со светлой/тёмной темой. Встроенный поиск и загрузка новых версий APK, push-уведомления, донаты и Telegram-контакт остаются в планах.

## Важно

Подсчёт тока и приблизительная смета **не заменяют** подбор кабелей/защиты и проверку соответствия действующим нормам. До публичного релиза требуется полноценная инженерная проверка.

## Графический редактор щита (0.7.0-alpha)

Вкладка «Щит» теперь открывает графическую сборку: **первым действием выбирается корпус** (условные типоразмеры на 6–72 модуля), после этого добавляются совместимые DIN-рейки. Аппараты изображаются векторными фасадами с клеммами, рычажками и обозначениями, а не текстовыми пунктами компоновки.

Порядок: выбрать щит → добавить DIN-рейку → открыть каталог → добавить аппарат → выбрать аппарат → нажать свободное место на рейке. Аппарат можно переставить касанием другой свободной позиции. При несовместимости корпуса и установленных реек изменение блокируется; данные проекта не удаляются.

Изображения — **условные, не точные фотографии или чертежи производителей**. Шины N/PE на экране декоративные; соединения и однолинейная схема пока не реализованы. Дальнейшие задачи: перетаскивание жестом, соединения, фирменные шаблоны аппаратов и графический PDF.

Миграция Room v3→v4 сохраняет все старые проекты. В резервных копиях JSON v3 сохраняется корпус, а старые файлы v1/v2 всё ещё можно импортировать.

## Ограничения редактора щитов

В версии 0.7.0-alpha это **только механическое размещение аппаратов на DIN-рейках**. Выбранная позиция не является электрическим соединением, а приложение пока не рассчитывает или не подтверждает безопасность схемы. Схема питания, УЗО, клеммы, шинопроводы, проводка внутри щита, проверка правил и однолинейный PDF будут реализовываться отдельно.

Элементы без ширины в DIN-модулях (например, кабели и наконечники) остаются в смете, но не размещаются на рейках. При удалении рейки снимается только компоновка, позиции сметы сохраняются.
