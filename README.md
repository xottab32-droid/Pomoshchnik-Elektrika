# Помощник электрика

Бесплатное Android-приложение для электриков. Исходники открыты для аудита: никакой рекламы, регистрации, аналитики и скрытой отправки пользовательских проектов.

**Статус:** 0.3.0-alpha, активная разработка. Это не готовое инженерное средство для проектирования безопасной электропроводки.

**Технологии:** Kotlin, Jetpack Compose, Room/SQLite. Планы, данные щитов и локальный каталог хранятся на устройстве; серверные функции пока не подключены.

**Сейчас:** проекты, предварительная компоновка щита, базовые помещения, калькулятор тока, предварительная смета, тестовый PDF.

**В планах:** редактор DIN-реек, топология однолинейной схемы, кабельные трассы, нормативные проверки, полноценные PDF, серверное обновление каталога и APK.

## Сборка
JDK 17, Android SDK Platform 36, Gradle 8.13:
```sh
gradle :app:testDebugUnitTest :app:assembleDebug
```
GitHub Actions собирает debug APK при коммите. Пока сборка не прошла CI, файл не следует считать рабочим.

## Приватность
Приложение пока не запрашивает разрешение INTERNET. Проекты остаются на телефоне, резервное копирование ОС отключено. Контакт Telegram и реквизиты добровольных донатов добавим перед релизом.
