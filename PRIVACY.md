# Приватность «Помощника электрика»

Актуально для `0.5.0-alpha`.

- **Локальные данные:** названия объектов, аппараты щита, цены, сохранённые сметы, резервные копии JSON и устаревшие данные помещений живут в SQLite/Room на телефоне. Приложение их не загружает на сервер.
- **Сетевое разрешение:** `android.permission.INTERNET` используется только по нажатию «Обновить базу» для HTTPS GET на `olqazmqalxtqznehpmkb.supabase.co`, по адресу `/rest/v1/catalog_releases`. Запрос получает опубликованную версию и список оборудования.
- **Что уходит в сеть:** стандартные технические HTTP-данные (включая IP-адрес, необходимый для HTTPS-соединения) и публичный ключ проекта Supabase. Не отправляются пользовательские проекты, цены смет, контакты, учетные записи, геолокация и аналитические события.
- **Без интернета:** приложение продолжает работать с локальным каталогом. При ошибке обновления установленная версия не удаляется.
- **Реклама и аналитика:** сторонние рекламные и аналитические SDK отсутствуют. Аккаунтов и обязательной регистрации нет.
- **Резервные копии:** создаются и импортируются через системный выбор файлов Android по инициативе пользователя. Автоматическое резервирование Android отключено через `allowBackup=false`.
- **Будущие функции:** обновление APK и необязательные push-уведомления пока не подключены. Их сетевое поведение будет документировано отдельно перед внедрением.

Исходный код и публичные эндпоинты доступны для проверки: https://github.com/xottab32-droid/Pomoshchnik-Elektrika.
