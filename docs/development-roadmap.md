## Правила разработки
1. Все изменения фиксируем в GitHub, CI тестирует debug сборку.
2. Нет подмены инженерных проверок приблизительными расчётами.
3. Сохраняем цены на момент добавления в проект.
4. Офлайн-работа обязательна, интернет — только явные обновления.
5. Защитить данные пользователей от случайной потери при миграциях.
