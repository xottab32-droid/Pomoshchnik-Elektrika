## Качество и безопасность
- Текущая альфа **не запрашивает INTERNET**.
- Проекты и цены хранятся локально, приложение не имеет серверной синхронизации.
- Сохранённые цены — снимки на момент добавления; неизвестная цена не считается нулевой.
- Без реальных кабельных трасс нельзя рассчитывать метраж по одним размерам комнаты.
- Сборка debug APK не подтверждает корректность проектирования электросетей.
