- Это рабочая альфа, не нормативно проверенный инженерный продукт.

## Ближайшие шаги
1. Проверить установку debug APK и основные экраны на физическом Android.
2. Доработать каталог: категории, поиск по характеристикам, локальный прайс.
3. Начать отдельную модель механической компоновки DIN-реек, не выдавая её за электрическую схему.
4. После появления модели соединений — автоматическую однолинейную схему.
