## Принципы
- Сметы и данные пользователей остаются на телефоне.
- Только запрос опубликованного каталога при нажатии «Обновить базу».
- Публичный ключ Supabase не предоставляет запись; секреты не включаем в APK.
- При потере интернета или ошибке данных прежняя локальная версия сохраняется.
- Не выдавать расчётные рекомендации за нормативно проверенные.

Почему ранее установка поверх старой версии не работала: GitHub Actions подписывал `app-debug.apk` новым временным ключом. Android отклоняет APK с несовпадающей подписью. Это нельзя исправить только увеличением `versionCode` — нужен единый постоянный ключ. **Для перехода со старого debug APK потребуется один раз экспортировать проекты и переустановить приложение**, затем подпись не должна меняться.

PR #5 объединён: https://github.com/xottab32-droid/Pomoshchnik-Elektrika/pull/5.

Инструкция: [release-signing.md](release-signing.md). Выполненный прогресс **23/52** пока не меняется: первый подписанный APK ещё не выпущен без установки секретов. Прогресс никогда не подразумевает, что проблема с обновлением на телефоне уже проверена.
