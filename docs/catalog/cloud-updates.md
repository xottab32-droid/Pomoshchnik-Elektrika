# Облачный каталог — Supabase Free

Сервис: `https://olqazmqalxtqznehpmkb.supabase.co`. Сервер хранит **только опубликованные версии оборудования**. Проекты, помещения, сметы и адреса заказчиков остаются на устройстве.

## Как работает кнопка «Обновить базу»

1. При явном нажатии приложение делает один HTTPS GET к `/rest/v1/catalog_releases?select=version,payload&published=eq.true&order=published_at.desc&limit=1`.
2. В запросе содержится публичный `sb_publishable_...` ключ Supabase, без авторизации пользователя и без данных проекта.
3. Приложение сверяет версию. Если новая, скачивает весь пакет (в том же ответе), проверяет формат, поля, размер, цены и уникальность ID.
4. Только после проверки заменяет локальный каталог в единой транзакции Room; сметы и сохранённые цены не меняются.
5. При недоступности сети, отсутствии публикации или ошибке в каталоге прежние записи остаются на телефоне.

**Никакого импорта каталога через файл в интерфейсе нет.** Импорт/экспорт JSON для *пользовательских проектов* сохранён как ручная резервная копия.

## Публикация для администратора

- База Supabase: `catalog_releases`.
- В таблице `payload` — полная JSON-структура каталога, пример: [seed-2026.10.30.1.json](seed-2026.10.30.1.json).
- Для выпуска добавь новую строку с уникальным `version`, `published=true`, `published_at=now()` через SQL Editor или будущую админ-панель. Дата публикации определяет актуальную версию.
- Установленный формат JSON: `format = ru.pomoshchnik.elektrika.catalog`, `schemaVersion = 1`, `items = [{id,category,name,unit,modules,priceKopeks}]`.
- `priceKopeks = null` означает «цена неизвестна»; нельзя выдавать пустой прайс за окончательную стоимость.

SQL-схема: [create_read_only_catalog_releases.sql](../supabase/migrations/20261030154227_create_read_only_catalog_releases.sql).

**Безопасность:** Postgres RLS разрешает роли `anon` только SELECT по `published=true`; INSERT/UPDATE/DELETE для `anon` и `authenticated` отозваны. Секретный серверный ключ **никогда** не внедряется в APK. Из-за изменений Supabase с 30.10.2026 SELECT выдан через явный GRANT.

На дату первого выпуска на сервере опубликована `2026.10.30.1` (32 типовые позиции без цены). Не публикуй непроверенные прайсы.

## Приватность

Supabase получает обычный HTTPS-запрос, IP-адрес и стандартные технические HTTP-метаданные для обслуживания API; приложение само не отправляет содержимое проектов, номер телефона, аккаунт или аналитику. Проверка версии происходит только по нажатию кнопки. Резервные копии проектов полностью локальные. Интернет нужен только для облачных возможностей; основные функции офлайн.

Автообновление APK и push-уведомления — отдельные будущие задачи.
