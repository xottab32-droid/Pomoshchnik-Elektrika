# Резервные копии проектов

Формат: `ru.pomoshchnik.elektrika.project`, версия схемы `1`, UTF-8 JSON.
Импорт и экспорт доступны без подключения к интернету через системный файловый диалог Android.

## Состав
- `project.name` — название объекта.
- `parts[]` — оборудование щита: `productId`, `name`, `unit`, `priceKopeks` (целое число или `null`), `modules`, `quantity`.
- `rooms[]` — помещение: `name`, `widthM`, `lengthM`, `heightM`, `sockets`.

JSON не включает ID устройства, аккаунт, контакт Telegram, токены, настройки телефона и сетевые данные. Система файлов Android сама определяет, куда пользователь сохранит файл.

## Поведение импорта
1. Проверяется формат/версия и размер до 4 МБ.
2. Проверяются текстовые поля, размеры помещений, цены и количества.
3. После полной валидации создаётся **новый** проект с новыми ID для всех записей.
4. Запись выполняется одной транзакцией Room/SQLite. Ошибки не должны оставлять частично импортированный объект.
5. Каталог оборудования не заменяется, а исторические цены остаются в проекте.

## Ограничения
- Не более 5000 аппаратов и 1000 помещений в одной копии.
- Сохранённые копии являются самостоятельными файлами. Удаление приложения без предварительного экспорта может привести к потере проектов; автоматическое Android-бэкапирование отключено для прозрачности.
- Формат JSON в текущем прототипе охватывает существующую модель комнат и аппаратов; будущие кабельные трассы и соединения потребуют расширения формата с миграциями.
- Нет шифрования: пользователь должен самостоятельно защищать файлы с планировками и адресами.
- Не импортируй файл из неизвестного источника, если не доверяешь его содержимому.

## Пример структуры

```json
{
  "format": "ru.pomoshchnik.elektrika.project",
  "schemaVersion": 1,
  "project": {"name": "Квартира"},
  "parts": [
    {
      "productId": "a2",
      "name": "Автомат 1P C16",
      "unit": "шт",
      "priceKopeks": 12500,
      "modules": 1,
      "quantity": 1
    }
  ],
  "rooms": [
    {"name": "Кухня", "widthM": 3.5, "lengthM": 4.0, "heightM": 2.7, "sockets": 4}
  ]
}
```
