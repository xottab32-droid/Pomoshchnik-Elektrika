# Резервные копии объектов — формат 3 (0.7.0-alpha)

**Новый формат:** `ru.pomoshchnik.elektrika.project`, `schemaVersion: 3` (UTF-8 JSON).
**Совместимость:** копии со `schemaVersion: 1` и `2` из предыдущих выпусков продолжают импортироваться, без компоновки DIN-реек.
Экспорт и импорт доступны офлайн через системный файловый диалог Android.

## Что экспортируется
- `project.name` — название объекта.
- `parts[]` — оборудование, цена в копейках на момент добавления, количество, ширина в модулях и локальный `backupId` для связей.
- `cabinet` — выбранный типоразмер корпуса (`modelCode`, `rows`, `modulesPerRow`) или `null` для старых объектов.
- `rails[]` — DIN-рейки, длина в модулях, порядок и технический `backupId`.
- `placements[]` — размещение аппарата на конкретной рейке, нулевой индекс начального модуля.
- `rooms[]` — **устаревший** раздел прежнего прототипа, хранимый исключительно для совместимости. Пользовательского редактора планировки больше нет.

Устройство, аккаунты, номера телефона, сетевые данные и ключи Supabase в резервную копию не записываются.

## Безопасный импорт
1. До записи проверяются формат и размер не более 4 МБ, состав и диапазоны полей.
2. Проверяется существование всех ссылок на рейки и аппараты, уникальность ID, ширина модулей, отсутствие пересечений, границы реек, количество аппаратов.
3. Создаются **новые** ID проекта, реек, аппаратов и помещений, чтобы не затронуть текущие объекты.
4. Весь проект записывается в **одной транзакции SQLite**. Ошибка импорта не должна оставлять частичные записи.
5. Для сохранённого корпуса отдельно проверяется соответствие его рядов и ширины DIN-рейкам. Несовместимый JSON отклоняется до записи.
6. Исторические цены из сметы не пересчитываются при изменении сервера.

## Пример v3
```json
{
  "format": "ru.pomoshchnik.elektrika.project",
  "schemaVersion": 3,
  "project": { "name": "Квартира" },
  "cabinet": {"modelCode": "universal-2x12", "displayName": "Щит 24", "rows": 2, "modulesPerRow": 12},
  "parts": [
    {
      "backupId": "part-example",
      "productId": "a2",
      "name": "Автомат 1P C16",
      "unit": "шт",
      "priceKopeks": 12500,
      "modules": 1,
      "quantity": 1
    }
  ],
  "rooms": [],
  "rails": [
    { "backupId": "rail-example", "name": "DIN-рейка 1", "capacity": 12, "sortOrder": 0 }
  ],
  "placements": [
    { "partBackupId": "part-example", "railBackupId": "rail-example", "startModule": 0 }
  ]
}
```

**Важно:** резервные копии — обычные JSON-файлы без шифрования; сохраняй их в защищённом месте. Перед удалением приложения обязательно сохрани нужные объекты.
